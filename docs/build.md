Одностраничный сайт на HTML, CSS и JavaScript. Для сборки и локального просмотра нужен
Node.js 24 или новее. Устанавливать npm-пакеты не требуется.

## Локальный просмотр

В корне репозитория выполните:

```sh
npm run preview
```

Команда собирает сайт и запускает его по адресу <http://127.0.0.1:4173>.
После правок выполните `npm run build` в другом терминале и обновите страницу.
Чтобы остановить сервер, нажмите `Ctrl+C`.

Открывайте сайт через этот сервер, а не двойным щелчком по `index.html`:
браузерные JS-модули используют `import/export` и загружаются через HTTP.

| Команда | Назначение |
| --- | --- |
| `npm test` | Проверить обработку отзывов, переводы и сборку |
| `npm run build` | Собрать сайт в `_site/` |
| `npm run build:feedback` | Обновить только данные отзывов в `js/generated/reviews.js` |
| `npm run preview` | Собрать сайт и запустить локальный сервер |

## Где что менять

| Задача | Файлы |
| --- | --- |
| Изменить текст на русском или английском | `js/locales/ru.js`, `js/locales/en.js` |
| Изменить структуру страницы, ссылки, метаданные или SVG | `index.html` |
| Изменить цвета, основной шрифт или ширину контейнера | `css/base.css` |
| Изменить общие кнопки, аватары или заголовки секций | `css/components.css` |
| Изменить шапку, меню или подвал | `css/layout.css` |
| Изменить оформление конкретной секции | Соответствующий файл в `css/sections/` |
| Изменить мобильное меню или переходы по странице | `js/navigation.js` |
| Изменить переключение языка | `js/i18n.js` |
| Изменить карточки отзывов или окно полного отзыва | `js/reviews.js` |
| Изменить прокрутку отзывов, стрелки или перетаскивание | `js/reviews-slider.js` |
| Добавить или исправить отзыв | `feedback/*.txt`, по [инструкции](../feedback/README.md) |

```text

  sections/

  main.js                 # Запуск модулей и связь между ними
  navigation.js
  i18n.js
  reviews.js
  reviews-slider.js
  locales/
    ru.js
    en.js
  generated/
    reviews.js            # Создаётся автоматически, не хранится в Git
feedback/                 # Исходные отзывы и инструкция

scripts/                  # Сборка и локальный сервер
tests/                    # Проверки на встроенном node:test
_site/                    # Готовый сайт, не хранится в Git
```

## Правила редактирования

**Тексты.** Значение `data-i18n` в HTML — ключ из языкового словаря. Основной источник
текстов — `js/locales/ru.js` и `js/locales/en.js`: при загрузке страницы JavaScript
подставляет значения из выбранного словаря. Ключи в обоих файлах должны совпадать.
`data-i18n-label` аналогично задаёт перевод атрибута `aria-label`.

В HTML также сохранён исходный текст для отображения до загрузки JavaScript и без него.
При изменении русского текста обновляйте соответствующий текст в HTML тоже.
Название страницы, метаданные, адреса и подписи без `data-i18n` редактируются в HTML.
Некоторые переводы содержат разметку (`<strong>`, `<br>`, `<span>`); сохраняйте нужные теги.

**Стили.** Мобильные правила `@media` находятся в файле соответствующей секции или
общего компонента. Общие элементы выносите в `components.css`, а оформление отдельной
секции держите в `sections/`. CSS подключается в `index.html` в порядке: базовые стили,
общие компоненты, общая раскладка, секции. При добавлении CSS-файла добавьте его туда.

**JavaScript.** Модули явно импортируют зависимости. `main.js` запускает навигацию,
создаёт слайдер и представление отзывов, затем связывает их с переключением языка.
Слайдер управляет прокруткой и состоянием перетаскивания; представление отвечает за
карточки и модальное окно. Переводчик не зависит от отзывов: он сообщает о смене языка
через callback, который задаётся в `main.js`.

**Отзывы и сборка.** Редактируйте только `feedback/*.txt`. Сборщик проверяет эти файлы
и создаёт модуль данных `js/generated/reviews.js`, затем копирует сайт в `_site/`.
Обе генерируемые папки исключены из Git. Не редактируйте их вручную — следующая сборка
перезапишет изменения. Файл `js/reviews.js` содержит логику интерфейса и редактируется вручную.

**Форматирование.** JS и CSS оформлены с обычными отступами; каждое CSS-свойство и
каждый ключ перевода расположены на отдельной строке. В репозитории есть настройки
Prettier для редактора. При желании можно отформатировать код командой ниже
(первый запуск загружает Prettier, но для сборки сайта он не нужен):

```sh
npx prettier@3.10.1 --write "js/**/*.js" "css/**/*.css" "scripts/*.mjs" "tests/*.mjs"
```

## Публикация

GitHub Actions запускает проверки и сборку при push и pull request в `main`.
После push в `main` содержимое `_site/` публикуется на GitHub Pages.
Настройки находятся в `.github/workflows/pages.yml`.
